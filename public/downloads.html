goooooook 下載

所有安裝檔由 GitHub Releases 發佈。請只從你自己 repo 的 Releases 下載，不要使用來歷不明的 APK 或安裝檔。

最新版本

開啟 GitHub Releases 下載對應平台檔案。

前往最新 Release 如果未見到安裝檔，表示尚未發佈 Release；請先等待打包 workflow 完成並發佈。

Windows

下載 .exe（NSIS installer），安裝後開啟 goooooook Host。

macOS

下載 .dmg，拖入 Applications。未簽名版本可能需要在系統設定允許開啟。

Linux

下載 .AppImage，設定執行權限後開啟。

Android

下載 .apk。正式版應為 signed release APK；debug APK 只供內部測試。

安裝時 Android 可能要求允許來自瀏覽器的安裝。

安全提醒

電視連結包含房間憑證，請勿公開或轉發。Host、手機與電視應連接同一私人 Wi-Fi。
