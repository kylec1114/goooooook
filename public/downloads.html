所有安裝檔由 GitHub Releases 發佈。請只從你自己 repo 的 Releases 下載，不要使用來歷不明的 APK 或安裝檔。

最新版本

開啟 GitHub Releases 下載對應平台檔案。

前往最新 Release 如果未見到安裝檔，表示尚未發佈 Release。

想即刻攞 APK？

而家仍未發佈正式 Release，所以「最新 Release」暫時未必有 APK。

你可以去 Actions → Android release APK，選 fix/core-auth-playback 後按 Run workflow。完成後喺該 run 底部下載：

goooooook-android-release＝正式簽名 APK
goooooook-android-debug＝內部測試 APK

開啟 Android 打包 GitHub Actions 需要帳戶 Billing／額度可用；debug APK 只適合內部測試。
